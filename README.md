## 🌆 Overview

Cyber-Cheems-2077 started as a joke between friends: what if the runner in *Cyber-Cheems* never had to worry about doge coins again? What began as a one-file experiment grew into a sprawling multi-module playground — a love letter to retro runners, neon dystopias, and the ridiculous joy of watching a counter spin to infinity.

The **Infinite Doge Vault Edition** reframes the original concept from the ground up. Instead of a quick script, we built an entire simulated economy layer: a persistent ledger, an adaptive spawn algorithm, and a responsive HUD that feels alive. Picture a vending machine that never runs out of snacks, humming quietly in a rain-slick alley while the rest of the world scrambles for change. That is the spirit of this repository.

The project rewards curiosity. Tinker with the vault parameters, remix the leaderboard, or port the HUD to your favorite engine — everything is modular, documented, and waiting for your fingerprints.

## 🚀 Core Features

- **♾️ Endless Vault Simulation** — A self-sustaining doge ledger that models inflow and outflow with weighted randomness, so the counter behaves like a real economy rather than a static number.
- **🎨 Responsive Interface** — Layouts adapt fluidly from ultrawide monitors to folding phones, with a neon-grid theme that scales gracefully.
- **🌍 Multilingual Support** — Community-maintained locale files for a growing list of languages, plus graceful fallback for untranslated strings.
- **🤝 24/7 Customer Support (virtual)** — An always-on assistant module with canned responses, FAQ routing, and a friendly tone that never sleeps.
- **🧩 Modular Architecture** — Swap the HUD, ledger, or spawn engine independently without breaking the rest of the stack.
- **📊 Live Statistics Panel** — Track coins-per-minute, streak multipliers, and vault health in real time.
- **🕹️ Controller & Keyboard Friendly** — Full remappable inputs, dead-zone tuning, and haptic feedback hooks.
- **🔒 Local-First Design** — Everything runs offline by default; no accounts, no telemetry, no surprise phoning home.
- **🎛️ Theming Engine** — Pick preset palettes or define your own with a short YAML manifest.
- **🧪 Simulated Environments** — Sandbox modes for testing balance changes without touching your live vault.

## 🗺️ Project Layout

- `core/` — Ledger, spawn engine, and the beating heart of the vault.
- `ui/` — Components, themes, and the responsive grid.
- `locales/` — Translation manifests organized by language tag.
- `support/` — Assistant scripts, FAQ routers, and canned responses.
- `sim/` — Sandbox environments for balance testing.
- `docs/` — Longform guides, architecture notes, and lore.
- `assets/` — Purely textual or vector assets (no external image hosting).

Each folder ships with its own README explaining purpose, conventions, and extension points.

## 🧠 Design Philosophy

We believe tools should feel like **friendly mentors**, not cryptic incantations. Three principles guide us:

1. **Clarity over cleverness.** If a newcomer cannot understand a module in five minutes, we rewrite it.
2. **Play as pedagogy.** Every mechanic doubles as a teaching moment about state, flow, and feedback loops.
3. **Respect the reader.** No dark patterns, no forced sign-ups, no nagging to upgrade.
